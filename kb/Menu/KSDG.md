# Menu KSDG – Khảo sát đánh giá

42 menu Edusoft (từ `web/edusoft-catalog.json`). Tên **có liên kết** = menu **tạo** dữ liệu (có ghi chú riêng); → [[…]] = dữ liệu menu đó đụng tới.
Phân hệ: [[KSDG]].

## An toàn dữ liệu
- Cấm xem thông tin chưa khảo sát đánh giá `ZA.02` → [[Ket qua khao sat]]
- Khóa form đánh giá `KFDG` → [[Ket qua khao sat]]
