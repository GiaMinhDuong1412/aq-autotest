# AQ – case nội bộ / sản phẩm chung

`school_code = AQ` trên ACS **không phải một trường**: case do AQ tự tạo (test release, cải tiến sản phẩm, lỗi phát hiện nội bộ) hoặc áp dụng cho **mọi trường**.

## Khi đọc case AQ
- Sửa ở phần **dùng chung** (Netweb chung, Edusoft chung) → có thể ảnh hưởng nhiều trường: case liên quan = case cùng phân hệ / cùng dữ liệu ở các trường.
- Case phát hiện khi test release (sheet Release(TestMenu)) thường gắn **một menu Edusoft cụ thể**.
- Test trên bản test chung (vd Edusoft HVNG - Copy) trừ khi case nêu trường cụ thể.
