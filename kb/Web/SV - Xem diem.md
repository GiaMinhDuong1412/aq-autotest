# Xem điểm

**Vai trò:** Sinh viên, Phụ huynh · **Menu trên web:** Xem điểm · Tài liệu: [[HDSD NETWEB]] (`NetWEB_SinhVienXemThongTinCaNhan`)

## Trên web
SV xem kết quả học tập: điểm thành phần, điểm TB tích lũy, số tín chỉ tích lũy.

## Kiểm tra liên kết khi test
- Sửa điểm / công thức tính TB trên Edusoft → kiểm "Xem điểm" của SV đó và "Xem kết quả học tập sinh viên" của CVHT.
- Điểm GV nhập trên web ([[GV - Nhap diem online]]) phải hiện ở cả Edusoft và trang này.
- Đổi chỉnh định / dữ liệu trên Edusoft xong: người dùng web **đăng xuất rồi đăng nhập lại** (Netweb giữ cache); nếu trường chưa khai `url_netweb` / BaseUrl ở `Hệ thống / Quản trị NetWEB / Chỉnh định chung` thì phải **Clear cache** ở trang quản trị (`/admin` → Quản lý App → Clear data App).
