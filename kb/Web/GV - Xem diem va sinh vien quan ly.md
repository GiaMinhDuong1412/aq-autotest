# Xem điểm môn giảng dạy, DS SV quản lý, kết quả học tập SV

**Vai trò:** Giảng viên · **Menu trên web:** Xem điểm môn giảng dạy · Xem DS sinh viên quản lý · Xem kết quả học tập sinh viên · Tài liệu: [[HDSD NETWEB]] (`NetWEB_GiangVienXemThongTinCaNhan`)

## Trên web
GV xem điểm SV các học phần mình dạy (mọi học kỳ). CVHT xem DS SV quản lý, đăng nhập vào từng SV để xem điểm, học phí, TKB; xem tiến độ học tập và thông tin liên hệ.

## Lấy dữ liệu từ Edusoft

- [[Lop sinh vien]]
- GV quản lý lớp (CVHT) gán ở lớp sinh viên ([[QLSV]]); điểm ở [[DIEM]]

- Đổi chỉnh định / dữ liệu trên Edusoft xong: người dùng web **đăng xuất rồi đăng nhập lại** (Netweb giữ cache); nếu trường chưa khai `url_netweb` / BaseUrl ở `Hệ thống / Quản trị NetWEB / Chỉnh định chung` thì phải **Clear cache** ở trang quản trị (`/admin` → Quản lý App → Clear data App).
