# Xem kết quả xét tốt nghiệp

**Vai trò:** Sinh viên · **Menu trên web:** Xem kết quả xét tốt nghiệp · Tài liệu: [[HDSD NETWEB]] (`NETWEB_XemKetQuaXetTotNghiep`)

## Trên web
SV xem tình trạng xét tốt nghiệp của mình (học phần, điểm TB, tín chỉ… đạt / chưa đạt) khi trường đã công bố.

## Kiểm tra liên kết khi test
- Chưa bật công bố ở Danh sách đợt xét → web báo chưa được xét / chưa công bố (không phải lỗi).
- Ba trường hợp cần kiểm: chưa xét hoặc chưa công bố · xét chưa đạt · đạt.
- Đổi chỉnh định / dữ liệu trên Edusoft xong: người dùng web **đăng xuất rồi đăng nhập lại** (Netweb giữ cache); nếu trường chưa khai `url_netweb` / BaseUrl ở `Hệ thống / Quản trị NetWEB / Chỉnh định chung` thì phải **Clear cache** ở trang quản trị (`/admin` → Quản lý App → Clear data App).
