# Kết quả khảo sát

**Tạo ở** [[KSDG]] – `Khảo sát đánh giá/ … DS đáp viên → đáp viên trả lời trên web → Khai thác báo biểu/ In kết quả`

## Dùng ở
- [[DIEM]] – DHNT: phải khảo sát xong mới xem điểm (web)

## Trên web
SV / GV / khách trả lời; GV xem kết quả.

## Khi dữ liệu này bị sửa / lỗi
Kiểm lại: [[DIEM]] và trang web liên quan.
