# Đơn từ trực tuyến (giấy chứng nhận)

**Tạo ở** [[QLSV]] – `Sinh viên/ Quản lý dịch vụ/ Cấp giấy chứng nhận/ Cập nhật giấy chứng nhận online` · SV đăng ký trên web, đơn vị xử lý duyệt trên Edusoft.

## Muốn có Đơn từ trực tuyến thì phải có trước
- [[Danh muc sinh vien|Danh mục sinh viên]] – SV đăng ký đơn bằng tài khoản web
- [[Hoc ky|Năm học – học kỳ]] – `nhhk_dk_giay_chung_nhan` ở Hệ thống / Quản trị NetWEB / Chỉnh định chung

## Dùng ở
- [[NETWEB-UI]] – SV đăng ký, theo dõi trạng thái, in trực tuyến; đơn vị ngoài tra cứu giấy xác nhận

## Trên web
SV đăng ký cấp giấy chứng nhận, xem trạng thái từng giai đoạn, in trực tuyến – xem [[SV - Dang ky cap giay chung nhan]].

## Khi dữ liệu này bị sửa / lỗi
- Kiểm trạng thái / phản hồi trên web khớp Edusoft; đơn nhiều giai đoạn phải duyệt đúng thứ tự.
