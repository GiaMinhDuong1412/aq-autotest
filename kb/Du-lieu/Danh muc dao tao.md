# Bậc – hệ – ngành đào tạo

**Tạo ở** [[KHGD]] – `Kế hoạch/ Quản trị phân hệ/ Quản lý danh mục/ Danh mục bậc đào tạo · hệ đào tạo · bậc hệ · ngành/chuyên ngành` · tầng 0 trong [[00 Logic nghiệp vụ]] (cần 0 loại dữ liệu có trước)
