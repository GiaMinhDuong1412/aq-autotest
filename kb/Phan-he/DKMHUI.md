# DKMHUI – Giao diện web đăng ký môn học

## Là gì
Phần **giao diện web** của đăng ký môn học (trang ĐKMH – nhiều trường tách riêng khỏi cổng SV để chịu tải, vd [[63194]] "Site đăng ký môn học mới").

## Phần trên Edusoft
Cài đặt nằm ở [[DKMH]] trên Edusoft (thời gian, ràng buộc).

## Phần trên web / app
Test trên **trang ĐKMH / cổng SV test** của trường, tài khoản SV (và GV-CVHT nếu duyệt).

## Test ở đâu
Chỉ web.

## Lưu ý khi test
Case [[64693]], [[64701]]. Thông báo / lặp dòng / hiển thị → test web; nếu case nói "setting" thì kiểm thêm chỗ cài trên Edusoft.
