# Chuc nang web theo truong

## Khi nào dùng
Case chức năng web chỉ một số trường có.

## Chuẩn bị
Xem ghi chú trường ở `Truong/` – trường có bật chức năng web đó không (sheet ChuyenDoiNetWeb), có trang riêng (ĐKMH) hay điều hướng theo cơ sở (DHNT).
## Các bước kiểm tra
1. Chỉnh định trên Edusoft (Hệ thống/ Quản trị NetWEB/ … hoặc thời gian mở trong phân hệ) nếu case liên quan.
2. Đăng nhập web test đúng vai trò, làm đúng thao tác KH nêu.
3. Kiểm dữ liệu ghi xuống Edusoft (nếu chức năng ghi dữ liệu: đăng ký, rút môn, nhập điểm, khảo sát…).
## Kiểm tra không ảnh hưởng
Vai trò khác (SV / GV / khách) và cơ sở khác vẫn đúng; ngoài thời gian mở thì bị chặn đúng thông báo.
