# Sửa hiển thị trên web

## Chuẩn bị
Trang web test của trường (bản có bản sửa), tài khoản test đúng vai trò KH nêu (SV / GV / quản trị), dữ liệu giống trường hợp KH gửi.

## Các bước kiểm tra
1. Vào đúng trang KH phản ánh, tái hiện như KH mô tả.
2. Kiểm tra **từng điểm** KH yêu cầu (thứ tự, cột, số liệu hiển thị khớp nhau…), chụp ảnh từng điểm.
3. Đối chiếu số liệu hiển thị với dữ liệu gốc (Edusoft) nếu case liên quan số liệu.

## Kiểm tra không ảnh hưởng
Các phần khác trên cùng trang; 1–2 trường hợp dữ liệu khác; thu nhỏ cửa sổ / trình duyệt khác.
**Không** chạy kịch bản Edusoft cho loại case này.
