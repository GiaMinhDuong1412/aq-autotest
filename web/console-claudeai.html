Hướng dẫn máy chạy thử

Cần có trên máy

  • Windows 10/11 và quyền quản trị (admin).
  • Edusoft bản test đã mở được trên máy, ví dụ thư mục EDUSOFT - HVNG - Copy.
  • Claude app (bản desktop) đã đăng nhập. Nhờ đó console gửi lệnh và lấy kết quả trực tiếp. Không có Claude app vẫn chạy được, chỉ phải lưu file lệnh và nhập kết quả bằng tay.
  • Mạng Internet ở lần cài đầu (tải Python và thư viện).

Các bước cài đặt (một lần cho mỗi máy)

  1. Khai báo trên consoleỞ thẻ Edusoft, dán đường dẫn đầy đủ tới Edusoft.NET.exe và nhập tài khoản test, rồi bấm Lưu.
    Lấy đường dẫn nhanh: trong File Explorer giữ Shift, chuột phải vào file Edusoft.NET.exe → Copy as path, dán vào ô rồi xóa hai dấu ngoặc kép.
  2. Tải bộ càiBấm Tải bộ cài (.zip) rồi giải nén ở đâu cũng được (vd thư mục Tải về). Không chạy thẳng trong file .zip.
    Thư mục cài lấy từ ô Thư mục bộ test trên máy này ở bước 2 (để trống = C:\Users\<tên bạn>\AQ-Autotest). Mỗi máy có thể cài một thư mục khác; cai-dat.bat hỏi lại khi cài, gõ thư mục khác nếu muốn.
  3. Chạy cai-dat.batBấm đúp cai-dat.bat, chọn Yes khi Windows hỏi quyền admin. Script tự làm:
    • cài Python 3.12 (qua winget) nếu máy chưa có;
    • cài thư viện (pywinauto, pillow, keyboard, keyring, openpyxl, obsws-python);
    • cài AQ Autotest Agent chạy nền cùng Windows để nhận lệnh chạy từ console;
    • chép bộ test vào thư mục cài cố định (thư mục giải nén xoá được);
    • đăng ký cầu nối aq-autotest vào Claude app của đúng người đang dùng máy;
    • in bảng kiểm tra (Python, thư viện, Edusoft.NET.exe, Agent, cầu nối, Claude app) và lưu ở chan-doan.txt; nếu Claude app cần nạp lại cầu nối thì hỏi và tự khởi động lại Claude app (Enter = đồng ý).
    Thấy dòng Xong. và các dòng [ OK ] là được. Nếu không tự cài được Python: tải từ python.org, khi cài tick Add python.exe to PATH, rồi chạy lại cai-dat.bat.
  4. Đã cài sẵn bộ test?Không cần cài lại: nhập đúng thư mục đã cài (nơi có aqrun.py) vào ô Thư mục bộ test trên máy này, bấm Tải file kết nối, bấm đúp ket-noi-claude.bat (không cần quyền admin). File tự tắt Claude app, nối với thư mục đó rồi mở lại Claude app.
  5. Kết nốiTrong Claude app (vừa được tự mở lại), mở console → Máy chạy thử → Kết nối. Bấm Cho phép khi Claude hỏi. Bước 2 chuyển sang dấu ✓ và hiện thư mục bộ test của máy này.
  6. Chạy test đăng nhậpBấm Chạy test đăng nhập. Sau vài giây cửa sổ đen mở ra. Lần đầu, nhập mật khẩu Edusoft 2 lần (gõ không hiện chữ). Mật khẩu được lưu trong Windows Credential Manager nên lần sau không hỏi lại. Script mở Edusoft, đăng nhập, thử các luồng sai (sai mật khẩu, bỏ trống tên…) rồi đóng Edusoft.
  7. Xem kết quảNếu đã kết nối, kết quả tự về console khi chạy xong (hoặc bấm Lấy kết quả mới). Nếu chưa kết nối, bấm Nhập kết quả… và chọn file AQ-ket-qua-….zip bộ test tạo trong thư mục Tải về (hoặc thư mục results trong thư mục bộ test). Đăng nhập đạt thì máy chuyển sang Sẵn sàng.

Trong lúc script chạy

  • Tắt bộ gõ tiếng Việt (Unikey/EVKey). Script gõ phím thật, kiểu gõ Telex có thể đổi chữ (ví dụ "dd" thành "đ").
  • Không chạm chuột và bàn phím cho tới khi script chạy xong.
  • Mỗi bước được chụp ảnh. Kết quả và file ket-qua.xlsx nằm trong results\<mã lượt chạy>; results\tong-hop.xlsx cộng dồn mọi lượt chạy.

Cập nhật bộ test

Không cần tải lại .zip. Mỗi lần bấm Chạy, lệnh mang theo bộ test mới nhất và cấu hình; Agent tự cập nhật rồi mới chạy. Chỉ tải .zip khi cài trên máy mới.

Tùy chọn: quay video

Mở OBS → Tools → WebSocket Server Settings → bật Enable WebSocket server (cổng 4455), rồi tick Quay video bằng OBS trong mục Thêm ở bước 1.

Kiểm tra đăng nhập Netweb

  1. Đường dẫnNhập địa chỉ Netweb của môi trường test, bắt đầu bằng http:// hoặc https://.
  2. Tài khoản testNhập mã và mật khẩu tài khoản sinh viên và/hoặc giảng viên test, rồi chọn tài khoản dùng khi kiểm tra.
  3. Lưu và yêu cầu kiểm traBấm Yêu cầu kiểm tra. Trạng thái chuyển "Chờ Claude kiểm tra".
  4. Nhắn ClaudeTrong cuộc trò chuyện, nhắn: kiểm tra đăng nhập Netweb. Claude mở Netweb trong trình duyệt của app, đăng nhập, chụp ảnh và cập nhật trạng thái.
  5. Sẵn sàngĐăng nhập thành công thì mở khóa chạy thử kịch bản Netweb. Đổi đường dẫn, tài khoản hoặc mật khẩu thì phải kiểm tra lại.

Kết quả không về console
Bấm Lấy kết quả mới, hoặc Nhập kết quả… và chọn file AQ-ket-qua-….zip trong thư mục Tải về.
  • Mật khẩu Edusoft không lưu trên console. Script hỏi trên máy của bạn và lưu trong Windows Credential Manager (mục AQ-Autotest:edusoft).
  • Mật khẩu Netweb lưu trong vùng riêng của tài khoản bạn trên trang này. Người khác, kể cả chủ trang, không đọc được. Claude chỉ đọc khi làm việc trong cuộc trò chuyện của chính bạn.

  • cai-dat.bat chỉ thêm mục aq-autotest vào cấu hình Claude app và sao lưu file cũ (.aq-backup) trước khi sửa.
