# Câu thông báo Edusoft (trích từ `Resources\Languages.xml` của bản cài)

Nguồn: file `Resources\Languages.xml` trong thư mục cài Edusoft (bản HVNG 2026-10) – danh mục câu chữ của chương trình,
13997 mục dạng `<Item ID="MA" Value="Câu chữ"/>`. Đây là **câu thông báo thật** dùng cho `expect:`/`ERR_PAT`/`OK_PAT` –
chép đúng từng chữ. Dưới đây chỉ là phần hay gặp; cần câu khác thì tìm trong file đó (máy chạy test có sẵn).
Ghi chú: "Danh sách đang chọn để xóa" KHÔNG có trong file → là tiêu đề lưới/màn hình sinh từ cấu hình.
