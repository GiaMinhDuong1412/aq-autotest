# Danh mục màn hình Edusoft.NET (cấu hình gốc AQ)

ribbon/cây chức năng; cột lưới = nhãn (Tenlabel) [MaField]; ô trên form sửa = `#MaField` dùng cho `type:`/`choose:`.
